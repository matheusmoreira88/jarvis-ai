JARVIS AI · Informações de privacidade / Privacy information

PORTUGUÊS (BRASIL)
Com a chave Gemini configurada, a voz e a visão contínua começam automaticamente nas próximas aberturas. O único modo de ativação é dizer “Jarvis”. Um modelo de português é baixado no primeiro uso e filtra a palavra no computador; somente trechos reconhecidos seguem ao Gemini para transcrição. A precisão varia conforme o microfone. Você pode desligar a escuta pedindo “Jarvis, desligar microfone” ou em Configurações; a escolha permanece nas próximas aberturas.
A tela escolhida nas Configurações é enviada à Gemini Live em até 1 imagem por segundo enquanto a visão está ativa. Isso pode consumir cota da API. Peça “Jarvis, desligar visão” para interromper; a escolha permanece nas próximas aberturas. Propostas de ação visual usam a tela principal.
O WhatsApp Web integrado pode usar microfone/câmera quando o próprio site solicita esse acesso. O JARVIS libera apenas esses tipos de permissão ao domínio oficial web.whatsapp.com. As permissões do Windows ainda se aplicam. Comandos que clicam, digitam, pressionam teclas ou enviam e-mails continuam sujeitos às confirmações de ação mostradas no aplicativo.
Lembranças e conversas ficam em SQLite local. É possível desativar o envio de lembranças salvas no contexto da IA nas configurações. Chaves de API ficam no cofre do sistema.

ENGLISH
With the Gemini API key configured, voice and continuous vision start automatically on future launches. The only wake phrase is “Jarvis”. A small Portuguese model downloads on first use and checks for the name locally; only detected utterances are sent to Gemini for transcription. Accuracy depends on the microphone. Ask “Jarvis, desligar microfone” or use Settings to turn listening off; that choice persists across launches.
The display selected in Settings is sent to Gemini Live at up to one image per second while vision is active. This may use API quota. Ask “Jarvis, desligar visão” to stop it; that choice persists across launches. Visual action proposals use the primary display.
Embedded WhatsApp Web may use the microphone/camera when the official site requests access. JARVIS grants only those media permissions to web.whatsapp.com. Windows permissions still apply. Commands that click, type, press keys, or send emails continue to require action confirmations inside the app.
Memories and chat history stay in local SQLite. Settings can prevent saved memories from entering AI context. API keys stay in the system credential vault.
